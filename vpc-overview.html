Architecture Map

The VPC domains that decide most answers

These four buckets capture the majority of SAA-C03 VPC questions: how networks are shaped, how traffic moves, how security is enforced, and how AWS services stay private.

Foundation

VPC core model

Get the Region versus Availability Zone boundaries right first. Most bad answers break here.

  • A VPC spans a Region, while each subnet exists in exactly one Availability Zone.
  • Default VPCs include an internet gateway and public default subnets in each Availability Zone.
  • AWS reserves five IP addresses per subnet, which affects usable capacity immediately.

Traffic

Routing and internet access

Most internet and hybrid questions reduce to route table targets and the direction of traffic flow.

  • Every subnet is associated with exactly one route table, and the most specific route wins.
  • Public IPv4 access needs both an internet gateway route and a public or elastic IP.
  • Private IPv4 egress uses NAT Gateway. Private IPv6 egress uses an egress-only internet gateway.

Security

Layered enforcement

Choose security groups, NACLs, and Network Firewall based on scope and inspection depth.

  • Security groups are stateful and allow-only, so they are the default choice for workload protection.
  • NACLs are stateless and support explicit deny rules at the subnet edge.
  • AWS Network Firewall is for centralized filtering, intrusion prevention, and deeper inspection.

Private Access

Endpoints and service reachability

The right endpoint depends on where the caller sits and whether traffic must leave the VPC boundary.

  • Gateway endpoints are free and only support S3 and DynamoDB from within the same VPC.
  • Interface endpoints use PrivateLink, create ENIs, and work for many AWS services.
  • Private DNS on the endpoint and VPC DNS settings must align for standard AWS hostnames to resolve privately.

Exam Traps

Facts worth memorizing exactly

These are the details that often separate the best answer from a tempting distractor.

1

Gateway endpoints do not support on-premises access. Use an interface endpoint over Direct Connect or VPN.

2

VPC peering is never transitive. If A talks to B and B talks to C, A still cannot talk to C through B.

3

NAT Gateway is IPv4 only. For outbound-only IPv6 internet access, use an egress-only internet gateway.

4

VPC Flow Logs capture traffic metadata, not packet payloads. Use Traffic Mirroring when payload inspection matters.

5

Hybrid DNS needs Route 53 Resolver inbound and outbound endpoints for full bidirectional name resolution.

6

Direct Connect is private but not encrypted by default. Add VPN on top when encryption is required.
